# blog-4: Population and Per Capita Income Across U.S.
This repository contains the R Markdown anddd the HTML file of blog 4.
This project uses the data of the population and the per capita income of all states in the U.S.. There are three visualizations including:
1. A dot plot of the population of each states in the U.S..
2. A scatter plot of the population of different states and the per capita income of these states.
3. A histogram of the distribution of the per capita income.
This analysis examines whether the states with a larger population have a higher per capita income.
